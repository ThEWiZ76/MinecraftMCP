# neoforge-v1.1.0-mc1.21.1

Public NeoForge release for Minecraft 1.21.1.

## Artifact

- `mcp-server-mod-neoforge-1.1.0+neoforge.mc1.21.1.jar`

## Highlights

- NeoForge 1.21.1 port of the Minecraft MCP client mod.
- HTTP MCP server inside the Minecraft client.
- Safe command execution plus opt-in arbitrary chat commands.
- Screenshot capture with optional camera position and rotation.
- GUI screen inspection and menu click automation.
- In-world right-click block/item tools, hotbar selection, movement, sneak, and chat wait tools.

## Install

Install NeoForge 21.1.233+ for Minecraft 1.21.1, then put the jar in the profile `mods` folder.

MCP endpoint:

```text
http://127.0.0.1:8080/mcp
```
